# 💖 Love App (Telegram Mini App & Bot)

Интерактивное веб-приложение (Mini App) с Telegram-ботом для пар, которые находятся на расстоянии. Позволяет отслеживать дни до встречи, вести общие списки планов, вещей и заметок.

## 🛠 Технологии
* **Backend:** Python, FastAPI, aiogram 3
* **Frontend:** HTML, CSS, JavaScript (Telegram WebApp API)
* **Инфраструктура:** Docker, GitHub Actions (CI)

## 🚀 Инженерные решения
* **Автоматизация (CI):** Настроен GitHub Actions, который при каждом коммите автоматически запускает тесты (`pytest`). Это гарантирует, что новые изменения не сломают существующую логику.
* **Тестирование:** Написаны unit-тесты для проверки логики сохранения и загрузки данных пользователя.
* **Контейнеризация:** Написан `Dockerfile` для быстрого и предсказуемого развертывания приложения на любом сервере (например, Render).
* **Безопасность данных:** Логика работы с файлами вынесена в отдельные функции с обработкой ошибок.
